# 天井クレーン シミュレーター

クレーン運転技術の向上を目的とした、物理演算を重視するブラウザベースの天井クレーン(橋形走行クレーン)シミュレーターです。GitHub Pages でそのままホスティングできる純静的サイトとして構成されています(ビルド不要・外部 CDN 依存なし)。

**操作の練習対象**: 玉掛け → 地切り → 走行/横行 → 振れ止め(追いノッチ) → 据え付け → 玉外し の一連の荷役サイクル、および実技試験形式の 2 コース(クレーン運転士実技試験・床上操作式クレーン技能講習)

## 使い方

### 操作方法

| 操作 | ペンダント | キーボード |
|---|---|---|
| 走行(西/東) | ◀ ▶ ボタン | ← → |
| 横行(北/南) | △ ▽ ボタン | ↑ ↓ |
| 巻上/巻下 | ▲ ▼ ボタン | W / S(歩行モード中は R / F) |
| 2速(高速) | Shift を併用 | Shift を併用 |
| 玉掛け/玉外し | 「玉掛け」ボタン | E |
| 非常停止 | 赤ボタン | Space |
| 警報ホーン | — | H(押している間) |
| 指差呼称 | — | V(技能講習モード) |
| 歩行 | — | WASD(歩行モード中) |

実機の押釦ペンダント同様、ボタンを**押している間だけ**動作します。1段押し(通常)が1速(微速)、Shift 併用が2速(高速)です。マウスドラッグで視点回転、ホイールでズームできます。

### 運転室(レバー)モード

トップバーの「運転室(レバー)」で、実機のクレーン運転席(キャブ)からのノッチ式レバー運転に切り替わります。

- **運転席視点**: ガーダ端部吊下げ形の密閉キャブ(実機の標準配置)。着座はガーダ軸沿い・反対側ランウェイ向きで、前面ガラスとグリッド付き**床窓**から直下のフックを視認する。画面ドラッグで見回し
- **ノッチ式コントローラー**: 0(停止)+ 各方向 5 ノッチ。速度基準は N1=10%(クリープ)/ N2=25% / N3=50% / N4=75% / N5=100%(インバータ多段速)。軽負荷倍速は最上段 N5 のみ増速。レバーは**ディテント保持式**(離しても戻らない)
- **レバー配置(教習標準)**: 左手 = 巻上(外)・横行(内)、右手 = 走行。前方押し = 巻下 / 北 / 西、手前引き = 巻上 / 南 / 東
- **操作**: レバーをドラッグ(ダブルクリックで中立)、またはキーで 1 ノッチずつ(← → 走行 / ↑ ↓ 横行 / W S 巻上下 / X 全中立)
- **3 動作同時投入は禁止**(実技試験仕様)。走行+横行の 2 動作(斜行)は可
- **ゼロノッチインターロック**(クレーン構造規格 34 条 2 項): 非常停止後は全レバーを中立(0)に戻すまで復帰しない
- ノッチ 0 への戻しはインバータの回生制動による減速停止(惰走ではない)。逆ノッチ(プラッギング)は速度基準が 0 を経由してランプするため、実機同様に急制動効果はない

### 歩行(床上)モード

「歩行(床上)」カメラで、床上からペンダントで操作しながら**荷と共に歩く**一人称モードになります。床上操作式クレーンの法的定義(ペンダントがトロリから吊下げ → 運転者はトロリに追従)どおり、**ペンダントケーブルの届く範囲(トロリ直下 約 1.6 m)** から離れられません。クレーンが動けばケーブルに引かれて追従します。

### 機体プロファイル(設定パネル)

| | 2.8t インバータ機(標準) | 5t 試験場仕様機 |
|---|---|---|
| 速度制御 | インバータ多段速(速度は荷に依らず一定) | **巻線形二次抵抗制御**(Kloss 式トルク曲線) |
| ノッチ 0 | 回生制動で減速停止 | **惰行**(ブレーキを踏むまで止まらない) |
| 速度の荷依存 | なし | あり(重荷重で失速、N1 では持ち上がらない) |
| 逆ノッチ | 効果なし(ランプ経由) | **プラッギング制動**が効く |
| コンタクタ | — | 1 段 0.7 s の順次投入(カチッと段が進む) |

試験場の実機(クレーン運転士実技試験で使われる旧式 5t 機)は二次抵抗制御で、荷の重さで速度が変わり、ノッチを戻しても惰行します。この「教習所と試験場の機体差」も再現対象です。

### 運転のコツ(実技のセオリー)

- **地切り**: 1速でロープを張り、荷が床を離れた直後に一旦停止して振れがないか確認する
- **加速**: 短くノッチを入れて荷が真下に来るのを待ってから加速する(2段起動)
- **振れ止め(追いノッチ)**: 停止後、荷が振れの最大(速度ゼロ)に達した瞬間に同方向へ1速でノッチを入れ、ロープとトロリが一直線になったら離す。振り子周期 T = 2π√(L/g)(ロープ 6 m で約 4.9 秒)の半周期を意識する
- **斜め吊り(横引き)は厳禁**: 接地した荷の真上に吊点を合わせてから巻き上げる(警告表示あり)
- **インチング**: 据え付け時は1速の短押しを繰り返して位置を微調整する

## 物理モデル

「ゲーム的な見た目の動き」ではなく、クレーン力学の文献と実機カタログ諸元に基づく力学モデルを 720 Hz の固定刻みで数値積分しています。

### 運動モデル(二質点・デカルト座標・完全ニュートン形式)

- **フック(玉掛け用具込み 30 kg)と吊荷を別質点**とする 18 状態の二重振り子系。ワイヤロープ(吊点→フック)とチェーンスリング(フック→荷重心)をそれぞれ**片側弾性要素**(伸びた時のみ張力)としてモデル化。二重振り子の 2 固有モード(高次モードはフック質量に反比例)が解析解と 1–3% で一致することをテストで検証
- **ロープ剛性** k = n·EA/L は JIS G 3525 6×Fi(29) φ12 ロープの実軸剛性(EA ≈ 7×10⁶ N)と掛数 n = 2 から算出
- **ロープ張力はブリッジ・トロリへ反力として作用**(完全双方向連成)。実機の 2.8t クレーンはブリッジ約 2.1 t・トロリ約 0.45 t と吊荷より軽く、荷振れの反作用が本体挙動に有意に影響する
- **吊荷ヨー(平面回転)**: 4 本吊りの張力に比例する復元トルク(4 点吊り振り子の等価ねじり剛性 k = T·r₁·r₂/h)。ねじり周期が解析解と 2% 以内・質量不変であることを検証
- **重心の偏り**: 設定パネルで荷の重心をずらすと、実物同様**重心が吊点の真下に来るまで荷が傾き**、4 本のスリング張力がてこの法則(玉掛け技能講習テキスト)どおり不均等になる(HUD の警告と荷重計に反映)
- **巻上ウインチは速度制御・逆駆動不能**(高減速比+電磁ブレーキ)としてロープ繰出し長 L(t) を規定入力に
- **走行・横行駆動はインバータ速度制御**(台形加減速ランプ+推力飽和)+粘性走行抵抗、または**二次抵抗制御**(Kloss 式 T(s) = 2Tb/(s/sm + sm/s)・コンタクタ 5 段)
- **ブレーキシーケンス**: インバータ機は「トルク確立 0.35 s → ブレーキ開放」「停止時 直流制動保持 → ブレーキ投入 0.15 s」(三菱 FREQROL ブレーキシーケンス機能の設定値)。試験場機は開放 0.18 s・投入 0.12 s の**トルク空白でわずかに荷が下がる**現象も再現
- **過負荷防止装置**(過負荷防止装置構造規格): 荷重計が定格の 105% を超えると巻上のみ遮断・連続警報。定格未満まで巻下げると復帰
- **地面接触**: ペナルティ法(反発ほぼ零)+正則化クーロン摩擦+静止摩擦。着床・地切り・斜め吊りの引きずり・**着床後のロープ弛み(フックの降下・スリングのドレープ)** が連続的に再現される
- **空力**: 風との相対速度による二次抗力(CdA = 1.8 m²)。突風はオルンシュタイン=ウーレンベック過程で生成
- **積分**: 古典 RK4・固定刻み 1/720 s(描画 60 fps から独立)

### 音響(全合成・音源ファイルなし)

WebAudio でモータ音・ブレーキ音・警報を**すべて実時間合成**しています。インバータ機はキャリア由来の 2 kHz 系ホイッスル+速度比例のスロット音、二次抵抗機は 100 Hz 電源ハム+うなり。ブレーキの開放カチッ/投入ゴトン、コンタクタの段進みクリック、着床の衝撃音、90% 荷重の断続警報・過負荷の連続警報・過巻警報・ホーン(H キー)を含みます。

### 検証(テストスイート)

`node --test tests/` で実行できる 48 テストで以下を検証しています:

1. 静的釣り合いで張力 T = mp·g(機械精度)
2. たるみ状態で張力ゼロ・自由落下
3. 散逸なし大振幅スイング 20 秒でエネルギー相対ドリフト < 1×10⁻⁶
4. 駆動なしで水平運動量が保存(ブリッジ/トロリ⇔吊荷の連成の検証)
5. 微小振幅周期が 2π√(L/g) と 0.3% 以内で一致
6. 球面振り子の鉛直軸まわり角運動量保存
7. 巻上仕事の収支 ΔE = ∫T·(−dL/dt)dt が 0.5% 以内で成立
8. **二重振り子の 2 固有振動数が閉形式解と 1–3% で一致**
9. **ねじり振り子(ヨー)周期が 4 点吊り等価剛性の解析解と 2% 以内・質量不変**
10. **偏心吊りの傾き角 tanθ = e/h と 4 本張力のてこ配分が解析解と 2% 以内**
11. **Kloss 駆動の定常速度(N1 = 同期の 79%・重荷重で N1 不揚)と惰行・プラッギング**
12. **過負荷防止装置の作動・復帰と巻上遮断**
13. 玉掛け→地切り→着床→玉外しの一連サイクル
14. ランダム操作 120 秒のファズテスト(NaN・発散なし)
15. 歩行オペレータのペンダントケーブル拘束
16. 指差呼称シーケンサ・円柱衝突・試験コース幾何
17. 回帰: 玉掛け射出防止・非常停止復帰条件ほか

さらに、**ラグランジュ法とニュートン法で独立に導出した剛体拘束モデル**(一般化座標 X, Y, θx, θy)との軌道相互照合テストを備えています(`tests/cross-model.test.mjs`)。

## 練習・試験モード

### 運搬課題

「運搬課題」ボタンで開始。開始ゾーンの荷に玉掛けし、ランダムに選ばれる目標ゾーンへ運搬して静かに据え付け、玉外しまでを採点します。100 点満点から「所要時間(基準 60 秒)」「運搬中の最大振れ幅」「据付誤差」「斜め吊りの累積時間」を減点。90 点以上で「模範運転」。

### 運転士実技試験(クレーン・デリック運転士免許 実技試験形式)

A–F の障害物(ポール門・バー障害×2・方向転換ポール・壁ギャップ)を順に経由する周回コース。1t 荷を**荷底 2.0 m** で搬送し、地切り 10–20 cm の一旦停止、バーの吊り越え、壁ギャップの**斜行**通過、着床前一旦停止までを実試験の減点方式(**合計 40 点以下で合格**)で採点します。機体は自動で 5t 試験場仕様機(二次抵抗制御)に切り替わります。終了後に減点表と振れ量で色分けした軌跡デブリーフを表示します。

> **コース寸法について**: 実試験のコースレイアウトは JEED 職業能力開発論文(兵庫)の図と受験報告に基づく**比例推定**です(実寸は非公開)。障害の種類・通過順・課題内容(2 m 搬送・一旦停止・斜行・減点 40 点以下)は公表資料どおりですが、寸法は本シミュレータのベイに合わせて調整しています。

### 技能講習(床上操作式クレーン技能講習 修了試験形式)

柵で囲われた矩形コースを、**ドラム缶(JIS Z 1600・バラスト 500 kg)** を低所搬送で 1 周します。床上操作式の定義どおり**歩行モード+ペンダント**で荷と共に歩き、**指差呼称(V キー)** を実施しながら運転します:

- 点検 10 呼称(周囲ヨシ〜押しボタンスイッチヨシ)→ フック位置ヨシ → 玉掛けヨシ → 垂直に上げます → 地切りヨシ → つり荷安定ヨシ → 方角呼称(西/南/東/北ヨシ)→ バー越えの巻上げ/巻下げヨシ → 着床ヨシ
- **呼称せずに動作を始めると「安全確認不足 −2」**(受講者報告の採点実態)
- 高さ約 2.5 m のバー障害は運転士試験基準(基発第 66 号 別図 2)を準用し、受け金具に約 5 cm 載っているだけなので**接触すると落下**(−10)
- 柵接触 −5、**つり荷の直下に入る**と −5(クレーン則 29 条)、**つり荷より前を歩く**と −5(メーカー取扱説明書の運転位置規則)
- 100 点から減点し **70 点以上で合格**(技能講習の合格基準慣行)。制限 7 分

## GitHub Pages でのホスティング
