# 天井クレーン シミュレーター

クレーン運転技術の向上を目的とした、物理演算を重視するブラウザベースの天井クレーン(橋形走行クレーン)シミュレーターです。GitHub Pages でそのままホスティングできる純静的サイトとして構成されています(ビルド不要・外部 CDN 依存なし)。

**操作の練習対象**: 玉掛け → 地切り → 走行/横行 → 振れ止め(追いノッチ) → 据え付け → 玉外し の一連の荷役サイクル

## 使い方

### 操作方法

| 操作 | ペンダント | キーボード |
|---|---|---|
| 走行(西/東) | ◀ ▶ ボタン | ← → |
| 横行(北/南) | △ ▽ ボタン | ↑ ↓ |
| 巻上/巻下 | ▲ ▼ ボタン | W / S |
| 2速(高速) | Shift を併用 | Shift を併用 |
| 玉掛け/玉外し | 「玉掛け」ボタン | E |
| 非常停止 | 赤ボタン | Space |

実機の押釦ペンダント同様、ボタンを**押している間だけ**動作します。1段押し(通常)が1速(微速)、Shift 併用が2速(高速)です。マウスドラッグで視点回転、ホイールでズームできます。

### 運転のコツ(実技のセオリー)

- **地切り**: 1速でロープを張り、荷が床を離れた直後に一旦停止して振れがないか確認する
- **加速**: 短くノッチを入れて荷が真下に来るのを待ってから加速する(2段起動)
- **振れ止め(追いノッチ)**: 停止後、荷が振れの最大(速度ゼロ)に達した瞬間に同方向へ1速でノッチを入れ、ロープとトロリが一直線になったら離す。振り子周期 T = 2π√(L/g)(ロープ 6 m で約 4.9 秒)の半周期を意識する
- **斜め吊り(横引き)は厳禁**: 接地した荷の真上に吊点を合わせてから巻き上げる(警告表示あり)
- **インチング**: 据え付け時は1速の短押しを繰り返して位置を微調整する

## 物理モデル

「ゲーム的な見た目の動き」ではなく、クレーン力学の文献と実機カタログ諸元に基づく力学モデルを 720 Hz の固定刻みで数値積分しています。

### 運動モデル(デカルト座標・完全ニュートン形式)

- **吊り質点**(フック+吊荷)は 3 次元の自由質点として扱い、ワイヤロープを**片側弾性要素**(伸びた時のみ張力を発生)としてモデル化。剛性 k = n·EA/L は JIS G 3525 6×Fi(29) φ12 ロープの実軸剛性(EA ≈ 7×10⁶ N)と掛数 n = 2 から算出
- **ロープ張力はブリッジ・トロリへ反力として作用**(完全双方向連成)。実機の 2.8t クレーンはブリッジ約 2.1 t・トロリ約 0.45 t と吊荷より軽く、荷振れの反作用が本体挙動に有意に影響する
- **巻上ウインチは速度制御・逆駆動不能**(高減速比+電磁ブレーキ)としてロープ繰出し長 L(t) を規定入力に
- **走行・横行駆動はインバータ速度制御**(台形加減速ランプ+推力飽和)+粘性走行抵抗
- **地面接触**: ペナルティ法(反発ほぼ零)+正則化クーロン摩擦+静止摩擦。着床・地切り・斜め吊りの引きずりが連続的に再現される
- **空力**: 風との相対速度による二次抗力(CdA = 1.8 m²)。突風はオルンシュタイン=ウーレンベック過程で生成
- **積分**: 古典 RK4・固定刻み 1/720 s(描画 60 fps から独立)

たるみ→再張架(スナップ荷重)、玉掛け・玉外し、過巻リミット、緩衝器、非常停止(全軸ブレーキ)も物理的に扱います。

### 検証(テストスイート)

`node --test tests/` で実行できる自動テストで以下を検証しています:

1. 静的釣り合いで張力 T = mp·g(機械精度)
2. たるみ状態で張力ゼロ・自由落下
3. 散逸なし大振幅スイング 20 秒でエネルギー相対ドリフト < 1×10⁻⁷
4. 駆動なしで水平運動量が保存(ブリッジ/トロリ⇔吊荷の連成の検証)
5. 微小振幅周期が 2π√(L/g) と 0.3% 以内で一致
6. 球面振り子の鉛直軸まわり角運動量保存
7. 巻上仕事の収支 ΔE = ∫T·(−dL/dt)dt が 0.5% 以内で成立
8. たるみ→張り遷移(スナップ)で発散しないこと
9. 玉掛け→地切り→着床→玉外しの一連サイクル
10. 走行 2 速到達と停止後の残留振れ
11. ランダム操作 120 秒のファズテスト(NaN・発散なし)
12. 回帰: 初期伸びが生じる高さでの玉掛け拒否(吊荷射出防止)
13. 回帰: 非常停止は操作ボタン全解放まで復帰しない

さらに、**ラグランジュ法とニュートン法で独立に導出した剛体拘束モデル**(一般化座標 X, Y, θx, θy)との軌道相互照合テストを備えています(`tests/cross-model.test.mjs`)。

## 実機調査(パラメータの根拠)

2.8t 床上操作式・インバータ制御クレーンの実カタログに基づきます:

| 項目 | 採用値 | 出典・根拠 |
|---|---|---|
| 巻上速度 | 1.3 / 8.0 m/min(軽負荷時 12) | KITO RYW 2.8t・三菱 U2-2.8 |
| 横行速度 | 4 / 24 m/min | 同上 |
| 走行速度 | 4 / 24 m/min | 日本ホイスト 2.8t×8m 組立図 |
| 加減速時間 | 巻上 1.5 s・横行 2.5 s・走行 3.0 s | インバータ標準設定 |
| ブリッジ質量 | 2.1 t(スパン 16 m 換算) | 輪圧から逆算(最大 1.7 t/輪) |
| トロリ質量 | 450 kg | 三菱 U2-2.8 概略質量 |
| ワイヤロープ | φ12 6×Fi(29) 2本掛け | JIS G 3525 |
| ロープ長範囲 | 0.9–7.4 m(周期 1.9–5.5 s) | 揚程 6.5 m 相当 |

## 運搬課題モード

「運搬課題」ボタンで開始。開始ゾーンの荷に玉掛けし、ランダムに選ばれる目標ゾーンへ運搬して静かに据え付け、玉外しまでを採点します。

**採点**: 100 点満点から「所要時間(基準 60 秒)」「運搬中の最大振れ幅」「据付誤差」「斜め吊りの累積時間」を減点。90 点以上で「模範運転」。

## 開発

```bash
# ローカル実行(ES モジュールのため HTTP サーバが必要)
python3 -m http.server 8080   # → http://localhost:8080

# 物理テスト
node --test tests/
```

## GitHub Pages でのホスティング

このリポジトリは追加ビルドなしで GitHub Pages にデプロイできます。

1. GitHub リポジトリの **Settings → Pages** を開く
2. **Source** で「**GitHub Actions**」を選択
3. `main` ブランチへ push すると `.github/workflows/pages.yml` がテスト実行後に自動デプロイ

(または Source を「Deploy from a branch」にして `main` / ルートを指定するだけでも動作します)

## 技術構成

- 描画: [Three.js](https://threejs.org/) r169(`js/vendor/` に同梱・外部 CDN 非依存)
- 物理: 自作(`js/physics/` — 依存ライブラリなし)
- テスト: Node.js 組込みテストランナー(`node --test`)
- UI: バニラ JS + CSS(フレームワーク非依存)
